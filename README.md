# Roll Coal, Make Hole 2: Company Man

A 3D satire of life as the Company Man on an Al Drilling rig (Al, not AI). Walk a modeled walking-rig location (box-on-box substructure, 25.5 ft drill floor, cantilever mast, side-by-side mud system, camp and gate), keep a live drilling sim on track, and survive increasingly ridiculous jobs — culminating in the Armageddon well from the original [Roll Coal Make Hole](https://github.com/beaubromley/roll-coal-make-hole).

Babylon.js + TypeScript + Vite. The location is procedural (merged primitives with world-scaled detail textures); props and the jointed crew are Blender-authored GLBs generated by `tools/blender/make_rig_kit.py` (rebuild: `"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b -P tools/blender/make_rig_kit.py`). If the models fail to load the game falls back to the procedural geometry.

## Run
```
npm install
npm run dev     # http://localhost:5173
npm run build   # type-check + production build into dist/
```

## Controls
WASD move · Shift sprint · Mouse look · Space jump · E interact · V first/third person · M mute · Esc close panel

## Layout
- `src/rig.ts` the location (rig, pad, camp, props, NPCs, far field)
- `src/sim.ts` drilling + well-control physics (ported from the original game)
- `src/game.ts` jobs/missions, panels (driller console, hopper, choke panel kill sheet, etc.), HUD logic, finale
- `src/tasks.ts` the job chain; every job has a minigame and a "wing it" shortcut whose consequence comes due later
- `src/minigames.ts` reusable minigames (sequence, pick, hold-to-dose, rhythm, mash, reaction, wires, typing, whack, slips, drill-off)
- `src/models.ts` Blender kit loader
- `src/player.ts` first/third person controller with AABB collision
