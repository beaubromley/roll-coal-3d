# Character model

Drop a rigged humanoid GLB here as `worker.glb` (Mixamo-style skeleton: Hips, Spine2, Head, LeftUpLeg, ... with clips named Idle / Walk / Run).
It replaces the Blender-built crew automatically. Use `?char=other.glb` in the URL to try a different file.
Without it the game falls back to the Blender kit.
