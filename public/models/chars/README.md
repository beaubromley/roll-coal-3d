# Character model

`worker.glb` is the Farmer by Quaternius (CC0, no attribution required). Everybody on location uses it, tinted per person.
Any rigged humanoid GLB with Idle / Walk / Run clips works: bone names for Quaternius (`Head_end`, `Chest`, `UpperLeg.L`...) and Mixamo (`HeadTop_End`, `Spine2`, `LeftUpLeg`...) are both recognised.
Use `?char=other.glb` in the URL to try a different file. Without `worker.glb` the game falls back to the Blender-built crew.
